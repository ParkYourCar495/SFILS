## Dataset Requirements

The original SFPL library usage dataset is not included because of its large file size.

Before importing data:

1. Obtain the SFPL library usage Excel workbook from the original Assignment 1 materials.
2. Place the workbook in the project's root `data/` directory.
3. Ensure the `EXCEL_FILE` setting in the root `.env` file points to the workbook's location.

The expected filename is:
`SFPL_DataSF_library-usage_Jan 2023.xlsx`
